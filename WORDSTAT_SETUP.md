# Подключение спроса из Wordstat

Вкладка «Спрос» сравнивает помесячную частотность запроса `автошкола`: январь–декабрь стоят на фиксированных местах, отдельная линия соответствует одному году. Москва и Санкт-Петербург загружаются отдельно. До подключения реальных данных график остаётся пустым.

## 1. Подготовить доступ в Яндекс Облаке

Откройте [консоль Яндекс Облака](https://console.yandex.cloud/) и подготовьте облако и каталог с доступом к Yandex Search API. Создайте сервисный аккаунт с ролью `search-api.webSearch.user`. Для него создайте API-ключ с областью действия `yc.search-api.execute`. Сохраните значение ключа и ID каталога.

Порядок действий и требования к доступу приведены в [официальной инструкции Wordstat](https://aistudio.yandex.ru/ru/docs/search-api/operations/wordstat-getdynamics). Используется новый Wordstat API в Yandex Search API; OAuth-токен Метрики для этого подключения не подходит.

Яндекс тарифицирует обращения к Wordstat. На дату подготовки, 26.10.2026, GetDynamics стоит 20 ₽ за 1000 запросов: обычное обновление двух городов требует двух запросов, около 0,04 ₽. Актуальные условия — в [тарифах Yandex Search API](https://aistudio.yandex.ru/ru/docs/search-api/pricing).

## 2. Добавить ключ на сервер отчёта

Откройте [проект Apps Script отчёта](https://script.google.com/home/projects/1uQWscOz9SvoLybnBZig0dSXcjK28MLc-UObrM1LGZ9UpIcS6Y-uI5JSI/edit), затем «Настройки проекта» → «Свойства скрипта».

Добавьте два свойства:

| Свойство | Значение |
|---|---|
| `WORDSTAT_API_KEY` | API-ключ сервисного аккаунта |
| `WORDSTAT_FOLDER_ID` | ID каталога Яндекс Облака |

Ключ вводится только в свойствах Apps Script. Не добавляйте его в исходники сайта, GitHub, Google-таблицу или поле пароля админки. Значения свойств не возвращаются в браузер и не выводятся в отчёт.

## 3. Проверить загрузку

Откройте [отчёт](https://alyayumm.github.io/prognozzz/) → «Спрос». После подключения сервер загрузит историю двух городов и сохранит её на листе `Wordstat_Demand` общей таблицы. Последующие открытия используют сохранённые данные. Когда появится следующий завершённый месяц, открытие вкладки обновит историю автоматически. Кнопка «Обновить Wordstat» запускает принудительное обновление при доступе к записи отчёта.

На 26 октября 2026 года последний завершённый месяц — сентябрь. Текущий месяц и будущие месяцы не заполняются нулями; линия заканчивается на последнем полученном значении. При ошибке сервиса сохраняется предыдущая успешная история и показывается сообщение.

## Что именно показывает график

- Запрос: `автошкола`, без ограничивающих операторов. Это частотность запросов с данным словом и словоформами, включая более длинные запросы, а не число уникальных людей.
- Все устройства; месячная детализация.
- Москва — регион `213`, Санкт-Петербург — регион `2`. Москва с областью не подменяет город.
- По умолчанию запрашиваются текущий и четыре предыдущих календарных года до последнего завершённого месяца. Фактическая глубина истории проверяется первым запросом после подключения.
- Каждый год занимает один ряд в таблице и одну линию на графике; пропущенные значения не соединяются и не превращаются в нули.

Контракт источника: [GetDynamics](https://aistudio.yandex.ru/ru/docs/search-api/api-ref/Wordstat/getDynamics), [коды регионов](https://aistudio.yandex.ru/ru/docs/search-api/reference/regions).
